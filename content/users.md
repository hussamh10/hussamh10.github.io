# How users shape platforms, and how platforms shape users.

I run observational and quasi-experimental studies of how users and communities
change online. Recommender and curation algorithms are trained on user behavior,
and platforms lean on that fact as a defense: the algorithm, they argue, only
reflects back what users repeatedly reveal they want. Undesirable behavior goes
in, gets reinforced, and ends up baked into the *weights*.

There is some truth to this but it remarkably misses the entire point. User behavior is not
a fixed input the platform simply reads — the platform helps shape it. So I
look for cases where behavior measurably shifts inside a platform, ask what
triggered the shift, and ask what could have been built differently. Users do
help construct the information structures they end up trapped in, filter bubbles
among them. But a design that incentivizes those structures should be changed.
